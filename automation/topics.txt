# Topics, grouped by category. Each day the job writes about one category,
# taking them in the order the [sections] appear below and wrapping round, so
# with eight sections every category gets a post every eight days. The section
# name is the category's slug on the blog (GET /api/categories/).
#
# Within a section the job takes the first topic it has not already covered.
# Nothing here is ticked off in a file. The job asks the blog what it has
# published and matches those titles back against this list, so the queue
# survives without the job ever writing to the repo.
#
# Lines starting with '#' and blank lines are ignored. Edit freely: add a topic
# to any section, add or reorder sections to change the rotation.
#
# When a section runs out the job asks the model for a fresh topic in that
# category, so the blog does not stop. Set STRICT_TOPICS=1 in the workflow if
# you would rather it stop and wait for you.
